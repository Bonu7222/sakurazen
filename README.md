# sakura zen 🌸

built this 2d canvas game bcs i wanted to make smth relaxing instead of the usual stressful action games. the goal is simple: catch falling cherry blosso,s with a basket and avoid the dark branches. its got a japanese aesthetic with a big red moon and mountains in the background.

## features

--canvas graphics: everything is drawn from scratch using javascript and html5. 
--collision detection: checking if the falling object hit the basket souds easy, but getting the hitbox right took some tweaking
--canvas gradients: drawing the background gradient and the glowing red moon withour making the canvas lag was a fun challenge.
audio context: generating sounds from scaratch using oscillators is still kinda confusing to me, but i managed to make a decent chime and a thud


overall, its a really chill game with aesthetic look.
